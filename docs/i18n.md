# Bahasa antarmuka

UI memakai Bahasa Indonesia secara default. Switch ID/EN tersedia di navbar warga dan Management, serta halaman autentikasi. Pilihan disimpan pada `localStorage` (`livon-language`) dan disinkronkan antartab. Perubahan bahasa tidak memuat ulang halaman atau mereset isian form.

`LanguageProvider` menyediakan `language`, `locale`, `setLanguage`, dan `t`. Gunakan `useLanguage()` dalam komponen interaktif atau `UiText` untuk label di dalam halaman server. Kamus ada di `src/lib/i18n/messages.ts` dan `extra-messages.ts`; placeholder `{0}`, `{1}` menerima nilai tanpa menerjemahkan isi pengguna. Formatter di luar React memakai `getDisplayLocale()` dan `translateDisplay()`.

Nama akun, judul/isi berita, postingan, komentar, nama proyek, kategori dari database, dan rincian tagihan yang ditulis pengelola tetap sesuai sumber. Nilai enum API/database dan perhitungan pembayaran tidak berubah. Popup Midtrans menerima opsi bahasa yang dipilih melalui Snap.

Verifikasi: tes kamus, placeholder, pesan notifikasi dan locale; tes regresi pembayaran/notifikasi/role; TypeScript dan ESLint; build produksi; pengecekan browser pada 13 halaman utama, persistensi pilihan, serta pelestarian isian donasi. Build Windows masih mengeluarkan peringatan penyalinan standalone `node:buffer` yang sudah ada.
